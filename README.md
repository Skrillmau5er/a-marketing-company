# A Marketing Company

An over-the-top animated marketing site: three themed pages built with Next.js 16, Tailwind CSS 4 and [Motion](https://motion.dev).

| Route | Theme | Highlights |
| --- | --- | --- |
| `/` | **Aurora** — dark neon | Rainbow cursor spark trail, mouse-reactive aurora + spotlight, 3D letter reveal, typewriter, magnetic buttons with confetti, scroll-velocity marquee, scroll-lit manifesto, 3D tilt cards, counters, interactive pricing lab (sliders, chips, toggle) |
| `/synthwave` | **Synthwave** — retro 80s | Perspective grid + striped sun, glitch title, scramble text, interactive terminal with auto-typing commands, live canvas "vibe mixer" with gliding presets, 3D flip cards, hold-to-launch button with screen shake |
| `/bloom` | **Bloom** — soft pastel | Gooey metaball cursor followers, bouncy letters, live brand-name typing, circular-reveal palette switcher, scroll-pinned horizontal gallery, before/after drag slider, spring accordion, petal bursts |

Shared: custom blend-mode cursor, animated nav pill, color-curtain page transitions. `prefers-reduced-motion` is respected.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and import the repo in Vercel — no configuration needed.
